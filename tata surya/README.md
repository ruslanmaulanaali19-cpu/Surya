# Jelajah Tata Surya — HTML Saja

Versi ini sengaja menggunakan HTML saja, tanpa file CSS dan tanpa JavaScript. Tampilan memakai gaya bawaan browser.

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Klik Mulai Pembelajaran untuk menuju menu, lalu pilih halaman yang diinginkan.

## File
- index.html: beranda
- menu.html: empat menu pembelajaran
- misi.html: CP dan TP
- planet.html: fakta delapan planet
- kuis.html: pertanyaan dengan jawaban yang bisa dibuka
- video.html: tautan ke YouTube

## Batasan
HTML saja bisa membuat navigasi antarhalaman dan membuka/tutup konten menggunakan `<details>`. Namun HTML saja tidak menyediakan penilaian skor otomatis atau desain visual khusus seperti CSS.
